Project

颐安智护 · AI 中老年养生防诈协同系统

技术核心 · 大三 · 中国国际大学生创新大赛校二等奖

01

项目背景 Problem

面向中老年群体在保健品消费和电信诈骗中的双重风险，设计一套"识别 + 问答 + 预警"的协同系统：长辈通过拍照识别保健品包装、语音提问，系统自动判断风险等级。

02

我负责什么 My Role

作为技术核心独立完成全栈：微信小程序前端 + SpringBoot 后端 + MySQL 数据库；负责模型接入、Docker 部署与 JWT 鉴权。具体包括用 YOLOv11 训练保健品包装识别（自建 2000+ 张实拍样本，准确率约 90%），结合 OCR 做三级风险预警；接入 BERT 做语音文字智能问答，用 LSTM 建模用户风险行为。

03

技术栈 Stack

YOLOv11 · OCR · BERT · LSTM · SpringBoot · MySQL · 微信小程序 · Docker · JWT。

04

成果 Result

获中国国际大学生创新大赛（2026）校赛二等奖；模型识别准确率约 90%，系统完成从采集、识别、问答到预警的完整闭环。

说明：本项目当时在团队/校内环境完成，源码未留存个人仓库，此处为项目真实介绍。
